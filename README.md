# pjecz-citas-v2-cliente

Página web sencilla que redirecciona al nuevo [Sistema de Citas](https://citas.saji.gob.mx/)

Hecho con Google Gemini.

## Implementación

1. Coloca ambos archivos (index.html y app.yaml) en la misma carpeta.
2. Asegúrate de tener una imagen llamada logo.png de 400x250px en esa misma carpeta.
3. Desde la terminal, con Google Cloud SDK configurado, ejecuta:

```sh
gcloud app deploy
```
